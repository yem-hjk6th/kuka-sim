# Hilbert corner test (simulation only)

Generated by `python scripts/run_hilbert_corner.py`. Nothing here was run on the robot; the KRL file carries the NOT RUN header. Every speed below is a **model estimate** unless it is a commanded value.

## Layout

- Hilbert curve order 3: 64 vertices, grid step 54.29 mm, side 380 mm, centre (685.5, -386.4) mm in BASE 0.
- Side and centre: fitted: largest square (rounded down to 10 mm) whose points are all reachable and collision-free with the vertical nozzle, at least 20 mm from any infeasible point and the bed edge (map grid 5 mm). The unreachable +X/-Y bed corner and the clamp boxes are outside it.
- Layer Z = bed top_z 0.95 + layer height 1.3 = 2.25 mm; nozzle vertical, rotation 0 deg about it (A0 B90 C0 for 0), TOOL 3.
- Path length 3420 mm, 50 corners (24 left, 26 right turns); model print time 287 s.

## Override schedule

- Straight: 12 mm/s at $OV_PRO 60 % ($VEL.CP = 20.0 mm/s at 100 %). Extruder rpm fixed.
- Corner: $OV_PRO = round(r x 60) %, from 10 mm before to 5 mm after the vertex (`schedule.csv`).
- Ratios 0.5, 0.7, 0.85, 1, 1.15, 1.3, 1.5, each at least 2x, seeded random order (seed 1).
- Minimum straight between override windows: 15 mm. **Assumption:** the extruder flow responds within a few tenths of a second; at about 12 mm/s 0.3 s is about 4 mm, so 15 mm (about 4 response times) keeps one corner's transient out of the next. Shorter -> r = 1.
- Straight lengths between windows: 39.3 .. 147.9 mm; vertex-to-vertex segments 54.3 .. 162.9 mm.
- Corners set to r = 1 because a neighbour is too close: none.

## Corner-speed model (estimate)

Assumptions: the C_DIS blend is the quadratic Bezier through the vertex as control point, of half-length d = min(C_DIS 3 mm, half the shorter adjacent segment); speed follows the commanded speed with a trapezoid profile at 500 mm/s^2 (assumed), is capped by sqrt(a_lat R) with a_lat 500 mm/s^2 (assumed); each override switch takes effect 0.1 s late (assumed). None of these numbers was read from the controller.

- Blend half-length 3 mm, min radius 2.12 mm; cap sqrt(a_lat R) = 32.6 mm/s.
- Predicted corner/straight ratio: 0.500 .. 1.500; max deviation from the commanded (quantised) ratio 0.000. Per corner: `waypoints.csv` (`model_ratio`), speed profile: `speed_profile.csv`, `speed.png`.
- Under these assumptions nothing limits the corner speed at the default settings, so the model simply returns the commanded ratio. It does not know the KRC's own override ramp, its look-ahead or any slow-down in approximate positioning; the logged speed decides.
- Predicted corner bead width relative to the straight bead (flow / speed at fixed rpm, no flow dynamics) = 1 / model ratio: 0.67 .. 2.00.
- Sensitivity to C_DIS (model): highest corner ratio before the blend radius caps the speed: C_DIS 0.5 mm -> 1.11, C_DIS 1 mm -> 1.57, C_DIS 2 mm -> 2.22, C_DIS 3 mm -> 2.71, C_DIS 5 mm -> 3.50.
